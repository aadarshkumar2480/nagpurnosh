# NagpurNosh

A responsive frontend web app for college students in Nagpur to discover nearby tiffin services and messes, browse weekly thali menus, compare meal plans, and submit registrations.

## Features

- **Search & Filters:** Filter messes by name or area (such as Katol Road, Dharampeth, Gittikhadan, Pratap Nagar, Sadar, and Manish Nagar) and filter by **All**, **Veg**, **Non-Veg**, or **Under ₹80**.
- **Mess Details Modal:** View meal timings, delivery info, pricing, ratings, and specialties for any listed mess.
- **Weekly Thali Menu:** Day-wise sample menu table covering weekdays, weekend specials, and Sunday thali.
- **Meal Plans:** Compare **Trial**, **Student Monthly**, and **Semester Saver** plans with pre-selection into the registration form.
- **Registration Form & Local Storage:** Validate student inputs, adjust per-meal budget with a slider, and view/clear saved registrations on the current device via `localStorage`.
- **Interactive UI:** Hero carousel, animated stats counters, scroll-reveal cards, active navbar highlight, toast notifications, and back-to-top button.

## Tech Stack

- **HTML5** (`index.html`)
- **CSS3** (`style.css`)
- **Bootstrap 5.3.3 & Bootstrap Icons** (loaded via CDN)
